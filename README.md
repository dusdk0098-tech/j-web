# J웹(제이웹)

건설현장 안전관리 웹앱의 초기 시험 구현입니다. 현재는 가상 데이터로 기능을 살펴보는 단계이며 실무 운영에 사용할 수 없습니다.

J웹 자체 코드는 [MIT 라이선스](LICENSE)로 제공합니다. 제3자 의존성에는 각각의 라이선스가 적용됩니다.

## 실행

Node.js 22.13 이상에서 의존성을 설치합니다.

```sh
npm install
```

검증은 `npm test`로 실행합니다. 현장과 출입자, 문서, 결재 이력은 `data/`의 SQLite 파일에 저장되고 Git에 포함되지 않습니다. Node.js 버전에 따라 SQLite 실험 기능 경고가 표시될 수 있습니다.

서버는 Node.js HTTP API를 제공하고 브라우저는 JSON 요청과 파일 첨부 요청으로 통신합니다. 기본 데이터베이스는 `data/jweb.sqlite`이며 `JWEB_DATA_DIR`을 설정하면 해당 폴더에 같은 파일명으로 저장합니다. 첨부파일과 시험 서명도 이 데이터베이스에 저장됩니다. 별도 클라우드 DB나 자동 백업은 구성하지 않으며 로그인 세션은 메모리에만 있습니다.

PowerShell에서 12자 이상의 시험 관리자 암호를 입력하고 실행한 뒤 이 컴퓨터의 브라우저에서 `http://127.0.0.1:4173/`을 엽니다. 암호를 설정하지 않으면 서버가 시작되지 않습니다.

```powershell
$env:JWEB_ADMIN_PASSWORD = [System.Net.NetworkCredential]::new('', (Read-Host '시험 관리자 암호' -AsSecureString)).Password
npm start
```

이 로그인은 단일 관리자와 로컬 서버에 한정됩니다. 서버를 재시작하면 로그인 세션이 만료됩니다. 다중 사용자, 현장별 권한, 안전한 외부 배포는 아직 지원하지 않습니다.

휴대전화 QR 시험을 위한 HTTPS 중계 주소는 `JWEB_PUBLIC_ORIGIN`에 경로 없이 설정할 수 있습니다. 예: `https://example.test:8443`. 이 경우 서버는 계속 `127.0.0.1`에서만 수신하며 지정된 호스트와 HTTPS 출처만 허용하고 QR에 지정된 주소를 넣으며 세션 쿠키에 Secure를 추가합니다. 주소 설정만으로 중계, 인증서 또는 방화벽이 만들어지지는 않습니다. 인증·권한·운영 보안이 미완성이므로 가상 자료만 사용하고 외부 공개나 실사용에 이용하지 마세요.

내장 시험 중계는 별도의 터미널에서 `npm run proxy`로 실행합니다. 서버와 중계에 같은 `JWEB_PUBLIC_ORIGIN`과 `PORT`를 설정하고, 중계에는 `JWEB_TLS_CERT`와 `JWEB_TLS_KEY`에 인증서와 개인키 파일 경로를 지정합니다. 중계는 기본적으로 이 컴퓨터에서만 수신합니다. 휴대전화 시험 시 `JWEB_PROXY_BIND`에 이 컴퓨터의 접근 가능한 IP 주소를 지정해야 합니다. 중계 포트는 HTTPS 주소에 지정하며 서버 포트와 달라야 합니다. 주소의 이름이 휴대전화에서 해당 IP로 연결되고 인증서가 그 이름에 맞으며 휴대전화에서 신뢰되어야 합니다. 네트워크와 방화벽도 해당 연결을 허용해야 합니다.

인증서와 개인키는 직접 준비하고 저장소 밖에 보관하세요. 이 중계는 접속 URL을 기록하지 않지만, 다른 중계나 서버를 사용할 때도 가입 토큰이 포함된 전체 URL을 접근 기록에 남기지 않도록 설정해야 합니다. 서버와 중계를 시작한 뒤에는 HTTPS 주소로 관리자 화면을 열어 시험 QR을 만듭니다.

예를 들어, 다음 예시의 주소·IP·파일 경로를 실제 준비한 값으로 바꾼 뒤 PowerShell 두 개에서 각각 실행합니다. 두 터미널의 주소는 같아야 합니다.

```powershell
# 첫 번째 터미널: 시험 서버
$env:JWEB_PUBLIC_ORIGIN = 'https://example.test:8443'
$env:JWEB_ADMIN_PASSWORD = [System.Net.NetworkCredential]::new('', (Read-Host '시험 관리자 암호' -AsSecureString)).Password
npm start
```

```powershell
# 두 번째 터미널: HTTPS 시험 중계
$env:JWEB_PUBLIC_ORIGIN = 'https://example.test:8443'
$env:JWEB_PROXY_BIND = '192.168.1.10'
$env:JWEB_TLS_CERT = 'C:\path\certificate.pem'
$env:JWEB_TLS_KEY = 'C:\path\private-key.pem'
npm run proxy
```

자동 시험은 OpenSSL을 사용할 수 있을 때 임시 인증서와 로컬 HTTPS 중계를 만들고 가상 가입 QR의 판독, 가입 및 로그인 API를 확인합니다. OpenSSL이 없으면 이 시험은 건너뜁니다. 이 시험은 실제 휴대전화나 운영용 인증서를 검증하지 않습니다.

## 현재 가능한 시험

- 현장 추가 및 현장별 출입자 등록·수정, 구분·소속·직종·등록 기간 검색과 검색 결과 엑셀 내려받기
- 현장별 협력사 회사명·공종 등록 및 수정 (시험용 독립 목록)
- 로컬 시험용 단일 관리자 로그인
- 가상 출입자의 날짜별·월별 출역 등록·취소와 현장별 인원 집계, 근로자·직종·소속별 기간 합계 및 날짜별 소속·직종·이름 검색
- 현장별 30일 가입 QR 생성·인쇄·중지, 별도의 지속적인 로그인 QR 및 가상 근로자 등록
- 현장별 가상 식당명과 식비·간식비·부가세 금액 등록 및 수정 (부가세 자동 계산 미구현)
- 날짜별 가상 출입자의 조식·중식·석식·간식 체크, 당시 식당명·단가 보존 및 근로자별 월간 기록 변경과 단가 합계 (부가세 제외, 실제 식대 미구현)
- 직영 가상 출입자의 신규 출역에 식사 종류별로 선택한 가상 식당 자동 적용 (현장관리자 자동 적용 미구현)
- 월간 가상 식대 명세서의 날짜별 내역, 식당·종류·기록 단가별 수량 및 합계와 인쇄 버튼 (부가세 계산 및 인쇄 양식 미검증; 이름·소속·구분은 현재 정보)
- 근로자별 월간 가상 출역일에 식사 종류별 기록 일괄 추가·삭제. 추가 시 기존 기록의 단가를 보존하며 출역 취소일의 기록은 일괄 삭제하지 않음
- 현장·근로자·월별 가상 노임과 여섯 공제 항목의 수동 입력 및 단순 차액 조회 (세금·공수 자동 계산과 실제 명세서 미구현)
- 가상 노임 화면과 엑셀에 조회 시점의 출역일·기록된 시험 공수·공수 미기록 일수 표시 (노임 금액에는 반영하지 않음)
- 가상 노임의 이름·소속·직종은 등록 시점 값을 보존하며, 이전 기록에 당시 정보가 없으면 '기록 없음'으로 표시
- 현장별 가상 자료실 글의 분류·제목·본문과 근로자 공개 설정, 시험 첨부파일 및 같은 현장 근로자의 공개 글·첨부파일 조회
- 현장별 가상 사진 업로드와 촬영일·설명 수정, 기간·검색어 조회 및 삭제
- 가입 링크로 현장별 시험 아이디·암호를 등록하고 별도 근로자 세션으로 로그인·로그아웃
- 관리자의 출역일별 시험 공수 수동 입력과 근로자 본인의 월별 출역일·기록된 공수 조회 (실제 공수 자동 계산은 미구현)
- 출역일별 시험 일당 입력과 공수를 곱해 원 단위로 반올림한 시험 계산액 조회 (저장된 노임과 지급액에는 반영하지 않음)
- 관리자 월별 출역과 기간별 근로자·직종·소속·구분 집계에 기록된 시험 공수와 미기록 일수 표시
- 근로자별 월간 출역 기록의 구분·소속·직종 일괄 변경 (가상 기록만 변경, 급여 일괄 변경은 미구현)
- 가입 시 가상 보호구 선택과 시험 서명 저장, 관리자의 현장별 가입 기록 조회 (실제 지급·본인 확인 미구현)
- 가상 출입자의 보호구 지급 수량을 별도로 기록하고 현장·월·종류별 집계, 관리자 출입자별 내역 및 근로자 본인 내역 조회 (가입 시 보호구 선택과 별개이며 실제 지급·수령 서명 미구현)
- 가입 시 선택 입력한 가상 생년월일·전화번호·비상연락처·주소·국적을 로컬 DB에 저장하고 관리자 가입 기록에 표시 (실제 개인정보를 입력하지 말 것; 본인 확인과 보관 정책 미구현)
- 관리자용 출입자별 가상 서류의 종류 선택·첨부·다운로드·삭제 (파일당 2MB, 출입자당 20개; 실제 신분증·계좌 등 개인 서류를 올리지 말 것)
- 로그인한 근로자의 현장에서 오늘 승인된 유해·위험 공지 조회 및 시험 서명 이미지 저장, 관리자의 공지별 확인 명단 조회 (본인·서명 진위 검증 미구현)
- 로그인한 근로자의 현장에서 오늘 승인된 TBM·안전교육 시험 참가 확인과 관리자 명단 조회 (서명 미구현)
- 근로자의 교육 종류별 당일 시험 참가 확인과 가상 서명 저장, 관리자 문서의 같은 현장·날짜·종류 확인자 표시 및 선택 (실제 교육이나 본인 인증 미구현)
- 로그인한 근로자의 네 항목 시험 자가점검과 손글씨 이미지 저장, 현장·날짜별 관리자 조회 및 시험 이미지 다운로드 (본인 인증·서명 검증 미구현)
- 관리자 시험 자가점검: 현장별 하루 한 번 세 문항의 O/X·비고와 시험 서명 저장, 당일 답변 조회와 이전 시험 내용 불러오기 (다중 관리자 식별·휴무 처리 미구현)
- 근로자의 실명·익명 작업중지 시험 요청과 PNG·JPEG 사진 첨부 및 현장별 관리자 조회 (알림 발송 미구현, 익명도 시각·내용·사진으로 유추 가능)
- 안전 문서 작성과 임시저장, 결재 요청·승인·반려 및 의견을 포함한 처리 이력, 유형·기간·내용 검색 (실제 결재자 인증·서명은 미구현)
- 작업계획서의 협의일·작업구분·작업기간과 선택 시간·업체·인원·장소·장비·위험요인·대책, 현장 출입자의 역할·가상 교육 및 자격을 시험 입력 (자격 검증·공식 점검표·결재선 연동 미구현)
- 시험 작업허가서의 위험작업 복수 선택과 업체·인원·기간·시간·장소·작업내용 저장, 문서별 사전 조치 시험 점검의 적정·미흡 판정과 조치 기록 (위험작업별 자동 점검 항목·실제 허가 및 서명 미구현)
- 시험 작업허가서별 가상 연장 기간·선택 시각과 시험 서명 저장, 수정 및 삭제 (실제 연장 승인·본인 인증 미구현)
- 시험 작업지시서에 현장별 협력사와 같은 소속의 가상 출입자 선택 또는 담당자 직접 입력, 제목·내용·첨부파일과 별도 시험 조치 기록 및 전후 사진 저장. 지정된 시험 계정은 지시서와 첨부파일을 조회하고 조치 내용·시험 서명·전후 사진을 저장할 수 있다 (외부 알림·수신 확인 미구현)
- 가상 재해 보고서의 사업장 개요·사고유형·점검실적·복수 재해자·발생 경위·조치·재발방지 대책 저장 (실제 신고·주민등록번호 미구현)
- 가상 산업안전보건관리비 사용내역의 항목·일자·단가·수량·시험 사진 저장과 현장·월별 합계, 작성 시점 내역과 사진을 보존하는 시험 월간 문서 (실제 결재선·법정 인정 여부 판단 미구현)
- 현장별 가상 장비의 기본 정보 등록·수정, 종류별 시험 증빙 저장, 계획서 장비 연결과 날짜별 가상 점검 항목·판정 기록 (공식 점검 항목·실제 결재 및 증빙 자동 인쇄 미구현)
- 작업계획서 결재 요청 시 연결된 장비 정보 보존 (이전에 저장된 계획서는 당시 장비 정보가 없을 수 있고, 첨부파일 목록은 현재 장비 기준)
- 날짜별 시험 장비 점검은 계획서와 별도 기록으로 저장하며 기록 당시 장비 정보 보존 (기존 점검에 당시 정보가 없으면 미기록으로 표시)
- 현장별 가상 줄걸이·체결장구 등록·수정, 규격·추가정보·제원과 시험 사진 저장, 검색 및 작업계획서 연결 (계획서에 연결된 장구는 과거 기록 보존을 위해 수정 제한; 사진의 계획서 자동 포함은 미구현)
- 현장별 가상 작업장소와 운행경로의 지형·지반·배수, 보강·지장물과 보호 대상별 안전시설 다중 선택, 운행경로 복사, 추가정보와 시험 사진 저장 및 계획서 연결
- 같은 현장의 이전 공지에서 빈 제목과 내용을 불러오기 (첨부파일은 복사하지 않음)

주간 시험 활동은 지정 시작일부터 7일의 출역, 문서 건수, 공지 및 문서별 교육 확인 수를 표시합니다. 모든 문서 상태가 건수에 포함되고 확인 수는 승인 문서의 시험 기록입니다. 안전 활동 등급 산식은 구현하지 않았습니다.
